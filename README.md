# Dawn

**Apple Watch 上的睡眠与晨间激活工具。** 用 3 分钟睡前呼吸帮你降下来，用一个诚实的智能唤醒窗口把你叫起来，用 10 秒晨间反馈攒下自己的数据。

```
夜间放松 → 短时感知 → 清晨唤醒 → 晨间激活 → 反馈改进
```

三条红线：不做医疗诊断 · 不宣称识别睡眠分期 · 不整夜常开传感器。没有可靠证据时，准时叫你，绝不瞎猜。

| 功能 | 说明 |
|---|---|
| 🫁 呼吸训练 | 4-6 节律（3/5 分钟，默认）/ 4-7-8（初学限 4 周期），相位触觉 |
| ⏰ 智能闹钟 | 截止时刻 + 27 分钟后台唤醒窗口，系统级触觉提醒 |
| 🔬 试响验证 | 2/3/5 分钟真实后台触发，验证的不是动画是能力 |
| ❤️ 健康只读 | 最近 7 晚睡眠分期 + 心率/呼吸频率（标明采样时间） |
| 📋 晨间反馈 | 困倦/舒适 0–10 + 离床状态，本地 JSONL 实验日志 |

**设备要求**：Apple Watch Ultra 2（watchOS 9+），配对的 iPhone，一台 Mac。免费 Apple ID 即可安装（无需付费开发者账号）。

## 一、安装教程（约 15 分钟）

### 第 1 步：准备 Mac

```bash
# 0. 克隆本仓库后，在仓库根目录操作：
cd dawn-watch

# 1. 从 App Store 安装完整 Xcode（必须，约 12GB，含 watchOS SDK）
# 2. 装完后切换命令行工具到 Xcode：
sudo xcode-select -s /Applications/Xcode.app
# 3. （可选但推荐）跑一键自检——逻辑断言 + watchOS 免签名编译：
./scripts/verify-with-xcode.sh
```

> ⚠️ 如果你的 Mac 命令行 Swift 工具链已损坏（`swiftc` 报 SwiftBridging 重复定义），上面第 2 步即可修复——完整 Xcode 自带匹配的工具链。

### 第 2 步：准备 Apple Watch

1. 手表与 iPhone 保持配对、蓝牙开启、和 Mac 同一 Wi-Fi；
2. iPhone 上 **设置 → 隐私与安全性 → 开发者模式**（如没有此选项，先做一次第 3 步，Xcode 会引导开启）。

### 第 3 步：安装到手表

1. 在仓库根目录打开工程：`open DawnWatch.xcodeproj`；
2. Xcode 左侧选中 **DawnWatch** target → **Signing & Capabilities**：
   - Team：选你的个人团队（Personal Team，免费）；
   - Bundle Identifier 若报重复，改成 `com.<你的名字>.dawnwatch`；
3. Xcode 顶部设备选择器：选你的 **Apple Watch Ultra 2**（可直接选表，或选配对 iPhone 后选"通过 iPhone 运行"）；
4. `Cmd + R`。首次会弹"信任开发者"，按引导在手表 **设置 → 隐私与安全性 → 开发者模式** 里打开并重启手表；
5. 手表表盘出现 Dawn 图标即成功。

> 安装问题排查：签名报错 → 重选 Team / 换 Bundle ID；找不到手表 → Xcode → Window → Devices and Simulators 确认设备在线；HealthKit 权限弹窗没出现 → 先删掉 App 重装。

## 二、iWatch 使用教程

App 四个入口：**呼吸 / 智能闹钟 / 健康数据 / 晨间反馈**，首页下方是实验日志流水。

### 1. 睡前呼吸（每晚可选）

呼吸页 → 选 `4-6` + `3 分钟`（或 `4-7-8` 初学模式）→ **开始**。
- 圆环随吸气涨、呼气缩；每次相位切换腕上轻拍一下（仅前台，屏幕暗了即暂停，不假装还在引导）；
- 可暂停/继续，**结束**随时可退。

### 2. 试响验证（第一次必做）

智能闹钟页 → 试响延迟选 `2 分钟` → **预约试响** → 按数字表冠回到表盘（让 App 进后台）。
- 约 2 分钟后会话自动启动，再过约 45 秒：**腕部持续触觉 + 系统闹钟横幅**；
- 不在 App 里时点横幅的 **Stop** 关闭；在 App 里则去反馈页保存即关闭；
- 回到首页日志应看到完整链路：`已预约 → 会话开始 → 已提醒(manual_test)`。

### 3. 明晨唤醒（正式使用）

智能闹钟页 → DatePicker 设截止时刻（默认 `07:30`）→ **预约明晨唤醒**。
- 戴表入睡。约 07:03 唤醒会话自动后台启动，每分钟一次运动观察；
- 默认行为：**07:30 准时触觉提醒**；
- 「允许提前唤醒（P1）」默认关闭。打开后需同时满足：昨晚睡眠数据充分（≥6h）+ 连续 2 个窗口运动量显著超当晚基线，才会在截止前提醒——且只标记为"运动候选"，不是"识别浅睡"；
- ⚠️ **验收通过前，永远同时保留一个系统原生闹钟保底。**

### 4. 醒后反馈（10 秒）

晨间反馈页 → 困倦 0–10 → 舒适度 0–10 → 离床状态 → **保存反馈**。可翻最近 7 条。

### 5. 看数据

- **健康数据页**：最近 7 晚各分期分钟数；最新心率/呼吸频率 + 采样时间（这是系统已有记录，不是实时值）；
- **首页日志**：全部事件流水；完整数据在 App 沙盒 `experiment.jsonl`（Xcode → Devices and Simulators → 下载容器，或等 V0.2 导出功能）。
